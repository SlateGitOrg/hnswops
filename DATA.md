## Synthetic fixture

Regenerate with

```sh
cargo run --release -- gen-fixture --out fixtures   # defaults: n=10000 queries=200 dim=32 clusters=32 spread=4 k=100 seed=41
```

A Gaussian mixture: 32 centers drawn from N(0, 10²) per axis, points drawn
around a uniformly chosen center with σ = 4. The 200 queries are drawn from the
same mixture **but never inserted** (held out). Ground truth is an exact
multithreaded L2 scan (`brute::exact_knn`). The generator uses `ln`/`cos` from
the platform libm, so regenerating on another OS may differ in the last bits;
the committed files and their pinned checksums are the reference.

Point tags used by the filter demos are derived from the key, not stored in
the files: tenant bit `key % 8`, plus a rare "flagged" bit (bit 8) on every
50th key (`cli::fixture_tags`).

## ANN_SIFT10K

* Source: INRIA TEXMEX corpus, <http://corpus-texmex.irisa.fr/>, file
  `ftp://ftp.irisa.fr/local/texmex/corpus/siftsmall.tar.gz`.
* Reference: H. Jégou, M. Douze, C. Schmid, "Product quantization for nearest
  neighbor search", IEEE TPAMI 33(1), 2011.
* Pinned archive SHA-256: `b8f1e59b20319ac44279d5251706909dd3a5b8ca5ce2a11ddb1e73902252770e`.
* Files used: `siftsmall_base.fvecs`, `siftsmall_query.fvecs`,
  `siftsmall_groundtruth.ivecs` (`siftsmall_learn.fvecs` is not used and not kept).
* Terms: the TEXMEX page distributes the data freely for research and
  benchmarking but states no explicit license. It is therefore **not
  redistributed** in this repository; `make fetch-data` downloads it from the
  original host and verifies the checksums. `make check` does not need it (the
  SIFT recall test skips with a message when it is absent).

SIFT10K is the small sibling of SIFT1M used by ann-benchmarks; its queries
are disjoint from the base set, so recall numbers on it are held-out numbers.
No parameter in this repository was tuned on SIFT10K: M=16 / efConstruction=200
are the textbook defaults, and the bench simply sweeps efSearch.
